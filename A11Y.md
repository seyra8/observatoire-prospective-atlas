## 3. Scripts de vérification locale

### Audit rapide avec axe-core (extension navigateur)

1. Installer [axe DevTools](https://www.deque.com/axe/devtools/) pour Chrome/Firefox
2. Ouvrir http://localhost:3000
3. DevTools > axe DevTools > Scan ALL of my page
4. Corriger toutes les issues "critical" et "serious"

### Test WAVE

1. Installer l'extension [WAVE](https://wave.webaim.org/extension/)
2. Activer sur chaque page
3. Vérifier : 0 Errors, 0 Contrast Errors

### Test Lighthouse (CI-ready)

```bash
# Depuis /web
npx lighthouse http://localhost:3000 --only-categories=accessibility --output=json --output-path=./lighthouse-a11y.json
# Objectif : score ≥ 95
```

### Test navigation clavier manuel

- `Tab` : parcourir tous les éléments interactifs dans l'ordre logique
- Premier `Tab` doit révéler le skip link
- `Shift+Tab` : parcourir en sens inverse
- `Enter` : activer liens et boutons
- `Esc` : fermer la command palette et dialogs
- `↑↓` : naviguer dans la command palette
- `⌘K` / `Ctrl+K` : ouvrir la command palette

## 4. Règles de rédaction pour les contributeurs (futurs éditeurs)

### Structure des fiches métiers
- Utiliser les niveaux de titre dans l'ordre (h2 → h3 → h4)
- Ne jamais sauter un niveau pour un effet visuel
- Un `<h1>` par page uniquement (le titre principal)

### Liens
- Texte du lien explicite hors contexte : `« Consulter l'étude Métiers 2035 »` (pas `« cliquez ici »`)
- Indiquer la nature si nécessaire : `« Rapport complet (PDF, 84 p.) »`
- Liens sortants : ouvrir dans un nouvel onglet uniquement avec `target="_blank"` + `rel="noopener"` + indication visuelle

### Images
- Alt text systématique :
  - Image décorative : `alt=""`
  - Photo contenant du texte : transcrire le texte
  - Diagramme : description succincte + long-description dans un `<details>` adjacent
- Ne jamais utiliser d'image pour un bouton de texte

### Tableaux de données
- Toujours inclure un `<caption>` résumant le contenu
- Utiliser `<th scope="col">` pour en-têtes de colonnes, `<th scope="row">` pour en-têtes de lignes
- Ne pas utiliser de tableau pour la mise en page

### Couleur
- Ne jamais utiliser la couleur comme seul vecteur d'information
- Exemple : un métier « en tension » doit afficher le texte « Tension » en plus du fond rouge
